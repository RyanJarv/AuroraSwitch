# Documentation

[Online firmware reference](https://aurora-switch.ryanjarv.sh/) is a
mobile-friendly version of the control reference.

- [User guide](user_guide.md): preparation, installation and firmware selection.
- [Firmware control reference](firmware_reference.md): selector colors, knobs,
  buttons, gates, modes, and version differences in one place.
- [How it works](how_it_works.md): the loader and its design choices.

[Development](development/README.md) contains onboarding, build internals,
[architecture](development/architecture.md), release checks and
[test commands](development/testing.md). Superseded
implementation notes remain in Git history rather than the active guides.
